Proxy

Proxy 对象用于创建一个对象的代理，从而实现基本操作的拦截和自定义（如属性查找、赋值、枚举、函数调用等）。

const target = {
  message: "hello world",
};
const handler = {
  get: (obj, prop) => {
    return prop in obj ? obj[prop] : "not fount prop";
  },
  set: (obj, prop, value) => {
    return value;
  },
};
const proxy = new Proxy(target, handler);
