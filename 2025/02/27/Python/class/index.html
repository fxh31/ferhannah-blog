deque

双端队列，可在两端快速进行插入和删除的序列容器。

  • append(x)：在右侧添加一个元素。
  • appendleft(x)：在左侧添加一个元素。
  • pop()：移除并返回一个右侧元素。
  • popleft()：移除并返回一个左侧元素。
  • extend(iterable)：在右侧添加多个元素。
  • extendleft(iterable)：在左侧添加多个元素（注意：添加的元素顺序会被反转）。
  • rotate(n)：向右旋转 n 步（负数表示向左旋转）。
  • clear()：清空所有元素。
queue = deque()
queue.append(1)
queue.popleft(2)
